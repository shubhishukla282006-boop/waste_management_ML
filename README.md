# Waste Management ML Project

This project predicts waste management cost and classifies disposal methods using Machine Learning models.

## Dataset
Waste_Management_with_Extra_Features.csv

## Models
- Random Forest Regressor
- Random Forest Classifier

## Results
- Accuracy (Classifier): ~0.21
- Feature Importance visualization for cost prediction

## How to Run
1. Install requirements: pip install -r requirements.txt
2. Run the notebook: Mnagement.ipynb
3. (Optional) Run Streamlit app: streamlit run app.py
